## Structure & Sections
- **Overview & Masthead**: Institutional and organization branding with upload placeholders.
- **Executive Team Roster**: Interactive expandable profile cards with role, focus, and bio.
- **Video Showcase**: 16:9 embedded video slot with duration guidelines and structural outline.
- **Theory & Theorist**: Karl E. Weick's Organizational Sensemaking Theory and rational alignment.
- **Reflections**: Five-sentence individual reflections with distinct member footnotes.
- **Commitments**: Four organizational pillars and communication standards.
- **Company Details**: Company profile and case analysis details.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Runtime**: React 19 / TypeScript
- **Styling**: Modern CSS variables, responsive design, and Google Fonts (Poppins)
- **Deployment**: Vercel CI/CD via GitHub
